# Requirement Traceability Matrix

**Document Version:** 3.0
**Last reviewed:** 2026-11-15

Version 1.0 of this file was written at project start and marked nearly everything NOT IMPLEMENTED. This version reflects the code on `main`. Paths are relative to `server/src/` (server) and `client/src/` (client). Overall narrative: [../implementation/current_state.md](../implementation/current_state.md).

"Tests" lists automated coverage only: **planner suites** = `server/src/features/planner/__tests__/` (11 engine tests + 15 adversarial scenarios); **e2e** = Playwright specs in `e2e/tests/`. "Swagger" covers `server/src/docs/swagger.yml`, which on `main` documents only the auth endpoints (all routes are documented in open PR #22). **unit** = `server/test/*.test.ts`; **smoke** = `scripts/smoke.d/*.sh` (real MongoDB, after merge). Status of work in open PRs is marked "(open PR #n)" and does not count as done.
